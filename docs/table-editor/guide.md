# Table Studio

[打开表格编辑器](https://superiorlqf.github.io/IC-Notes_Black-Iron-Series/table-editor/)。单文件 HTML，无外部运行依赖，下载 `index.html` 后可离线使用。

## 复制与粘贴

- 单击选择单元格，Ctrl/Cmd+C 复制整个单元格或选区；支持合并单元格、格式及明确设置的行列尺寸。
- 双击进入编辑，选中部分字符后复制，只复制这段文字及其格式。粘贴到另一格或编辑中的光标位置，不引入段落包装造成的上下空行。
- 编辑状态支持 Shift+Enter / Alt+Enter 格内换行，保留主动输入的换行和空行。Ctrl/Cmd+Enter 完成编辑。
- 支持从 Excel、WPS、Sheets 粘贴 HTML 表格或制表符文本。

## 拖拽填充

选中一个或多个种子单元格，拖动选区右下角的绿色小方块，在现有表格内向上、下、左、右填充。

| 种子 | 延续结果 |
| --- | --- |
| `1` | `2、3、4…` |
| `1、3` | `5、7、9…` |
| `0.1、0.2` | `0.3、0.4…` |
| `-1、-3` | `-5、-7…` |
| `signal01、signal03` | `signal05、signal07…` |
| `A、B` | 循环复制 `A、B…` |
| 不规则数列 `1、3、8` | 循环复制 `1、3、8…` |

多列向下填充时，各列独立推算；多行横向填充时，各行独立推算。按住 Ctrl/Cmd 强制循环复制，Esc 取消拖动。一次填充可以用一次 Undo 撤销，也可 Redo 恢复，HTML 源码同步更新。

合并单元格不能作为填充种子；目标区域包含合并格时会拒绝本次操作并保留原内容，请先 Split。填充角与整表缩放箭头分别使用，绿色方块负责填充，表格外侧 ↘ 负责整表缩放。

## 表格间距

工具栏的 **Spacing** 对整张表生效，字号保持不变：

| 档位 | 上下内边距 | 左右内边距 | 行高倍数 |
| --- | ---: | ---: | ---: |
| Normal（正常） | 10 px | 12 px | 1.5 |
| Compact（紧密） | 4 px | 8 px | 1.3 |
| Very compact（很紧密） | 1 px | 4 px | 1.15 |

切换档位会清除固定的表格、行和单元格高度，并收紧格内段落间距，使行高自动适应文字。已有内容、字号、颜色和合并结构保留；可以一次撤销恢复原高度。之后仍可用 H 或拖拽设定行高，手动行高下限为 12 px，实际高度至少能容纳内容。新增空行和列沿用当前间距档位。

间距写入内联 HTML 样式，导出、重新导入和浏览器本地保存后均保留。导入的间距与预设不一致时显示 Custom。

## 浏览器回归

需要 Node.js、Playwright 与 Chromium。在仓库根目录运行：

```bash
node tests/table-editor.browser.cjs
```

可用 `CHROMIUM_PATH` 指定浏览器路径。测试包含真实系统剪贴板、局部文字格式和换行、四向填充、数列步长、复制模式、取消、合并保护、撤销重做、源文同步，以及原有表格编辑功能。
