Properties

Verdi-Like Shortcuts

Selection & Grouping:
Ctrl + Click : 多选信号
Ctrl + G : 将选中的信号建组
Delete / dd : 删除选中的信号/组
c : 重命名 / 修改属性

Wave Editing:
s : 编辑 Bus 的值
x / z : 设置为 Unknown/High-Z
Space : 保持并延续前一个状态
i : 插入/移除 Omitted Time Gap (虚线间隔)

Text Annotation Layer:
:text : 进入文本编辑模式
Wheel : 在文本上滚动滑轮以缩放字体
