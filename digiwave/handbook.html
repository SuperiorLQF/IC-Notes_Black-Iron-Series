快速开始

  1. 点击工具栏的加号，在菜单里选择 Binary Signal、Bus Signal 或 Clock Signal。
  2. 在左侧选择信号。点击波形时，光标定位到最近的边沿；距离相同时选择左侧边沿。零时刻也可定位。
  3. 按 I 进入 Insert，选择待画数值，再按回车填写持续时间。按 Esc 返回 View。
  4. 按 F 完整显示全部波形。
  5. 点击工具栏的保存图标，导出 JSON 工程。修改有误时按 Ctrl+Z 撤销。

工具栏图形按钮的作用可通过鼠标悬停查看。右侧状态显示导出及本地备份状态；底部显示模式、光标时间和缩放比例。

模式与光标

模式进入方式用途
View默认；Esc 返回选择信号、定位边沿和浏览。鼠标双击、拖动波形不会改变电平或边沿。
Edit选择信号后按 E修改已有波形段的值；拖动已选信号的边沿调整时间。
Insert选择信号后按 I在光标处插入一段波形，将后续波形向后推。
TextT添加、移动和设置注释。

光标框中心对准边沿：View 是常亮荧光青色，Edit 是闪烁亮粉色，Insert 是闪烁亮黄色。输入框聚焦时，按键用于输入文字或数值；操作波形前先回到画布。

在子操作中按 Esc 会先取消子操作，必要时再按一次返回 View。View 中仍可使用撤销、粘贴、删除等明确命令。

信号与分组

  • Binary Signal：普通二值信号，支持 0、1、X、Z。
  • Bus Signal：总线，可输入数值、X 或 Z；属性面板选择 Hex / Dec 显示。当前未提供位宽约束或按位展开。
  • 属性：选择信号后按 C，修改名称、颜色、线宽及总线显示进制。
  • 多选：在左侧信号列表用 Ctrl+点击增减选择。
  • 排序：拖动左侧通道行；放到展开的分组上可移入该组。
  • 分组：多选后按 Ctrl+G。点击组名前的三角折叠或展开；悬停组行后点击 Ungroup 解组。
  • 删除：按 Delete 删除选中的信号或标注，Ctrl+Z 可撤销。

添加时钟

打开加号菜单 → Clock Signal，填写：

字段说明
Name新信号名称；自动建议一个未被占用的 clk 名称。
Period输入正数，并在下拉框选择 ps、ns、us 或 ms。
Duty (%)高电平占空比，大于 0、小于 100。
Cycles周期数，1～10000 的整数。
Start time从零时刻起的绝对开始时间，数字和单位分别选择；不是相对当前光标的延迟。

例如 Period = 10 ns、Duty = 25、Cycles = 4、Start time = 2 ns：时钟从 2 ns 开始，每周期高电平持续 2.5 ns，结束于 42 ns。

点击 Add 或在输入框按回车创建。不需要预先选择信号，也不会覆盖已有信号。开始前为低电平，设定周期结束后为 Z。新建结果是普通二值信号，可继续编辑，并支持撤销。

编辑与插入

修改已有电平

  1. 选择信号并定位到要修改波形段的左边沿，按 E。
  2. 二值信号按 0、1、X 或 Z 设置待写值。
  3. 按回车应用，光标留在该位置。连续相同的段可能合并。

拖动边沿需要在 Edit 模式中操作已选信号；边沿不能越过相邻边沿。按 Esc 可取消正在拖动的修改。

插入一段波形

  1. 选择起始边沿，按 I，设置待写值。
  2. 按回车，填写持续时间，例如 10、0.5ns、2us 或 1ms，确认后插入。
  3. 也可点击光标右侧指定插入终点；后续波形会向后移动。

按空格时，若设置了参考吸附信号，就延续到它的下一个边沿；否则复用上一次的持续时间。空格保持待写值，鼠标或回车完成插入后，二值信号的 0/1 待写值会交替。

在 Edit / Insert 中按 Backspace，删除当前光标与前一边沿间的一段，并将后续波形前移。

总线输入

选择 Bus 后进入 Edit / Insert，按 V 打开底部数值输入框。输入十进制数、带 0x 前缀的十六进制数、X 或 Z。按回车应用修改或设置插入时间；Insert 下也可用空格插入。空格是编辑命令，不能作为总线数值的一部分。

重复片段

在 Edit / Insert 中按 R，依次选择片段的起止边沿，再填写重复次数。Insert 将片段重复插入当前编辑位置并后推已有内容；Edit 在当前位置重复覆盖。它与新建一个 Clock Signal 是两种不同操作。

框选与复制粘贴

在 View 中按住 Shift 拖动，选择时间范围，可跨多个通道。Ctrl+C 复制选区。选择数量、类型相匹配的目标信号并定位粘贴起点：

  • Ctrl+V：覆盖粘贴，保留粘贴区域之后的时间位置。
  • Ctrl+Shift+V：插入粘贴，将后续内容向后推。

复制内容保存在编辑器内部，不能直接从系统剪贴板粘贴其他软件的波形。源、目标通道按各自显示顺序配对。

缩放、浏览与吸附

操作效果
F / 左右展开图标完整适配全部波形，即使当前有框选也显示全部。
Ctrl+滚轮以鼠标所在时间为中心缩放。
滚轮上下浏览通道。
Shift+滚轮 / 横向滚动左右平移时间轴。
中键拖动平移视图。
↑ / ↓View 中切换通道。
← / →跳到前一个或后一个边沿；最后边沿之后不再向右移动。

最大缩小范围约为工程时长的 120%：时长 100 ns 时最多显示约 120 ns。工程时长取所有信号的最后一个存储事件时间；空工程使用默认范围。

工具栏网格数字以 ns 为单位，用于鼠标拖动等操作。磁铁旁的下拉框选择参考信号，可显示其边沿网格；空格插入优先延续到参考信号的下一个边沿。鼠标定位编辑光标始终选择最近边沿，与固定网格不是同一机制。

测量、事件连线和注释

  • 双游标：Alt+点击放置两个时间游标，底部显示 Δt；第三次点击开始新一组。
  • 测量标尺：按 M 或点标尺图标，再依次点击两个边沿创建测量。
  • 事件连线：按 A 或点弧线箭头图标，依次选择两个边沿；可拖动连线文字调整位置。
  • 注释：按 T，在左侧选择绑定信号，点击波形区域输入注释，回车确认。可拖动注释；选中注释后滚轮调整字号。
  • 属性：选中标尺、连线或注释后按 C。注释可设置 Sticky Note 便签内容；点击便签的折叠控件展开或收起。

保存、导入与恢复

保存图标导出 JSON，文件夹箭头图标导入 JSON。工程包含信号、分组、注释、标尺、连线和缩放比例。导入会替换当前工程；未导出时会提示确认，无效数据会拒绝导入。

Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做。当前最多保存 100 个历史状态，刷新页面后不会恢复撤销历史。

修改后会尝试保存浏览器本地备份；重新打开时可选择恢复，也可点击工具栏的恢复图标。浏览器权限、隐私模式、清理站点数据或更换打开位置都可能影响备份。

本地备份不是导出的文件。重要工程请主动导出 JSON。离开未导出的页面时，浏览器可能显示确认提醒。

黑白打印配色

点击打印机图标切换配色，再点一次返回彩色：

  • 普通 0/1 波形、总线数值、文字、标尺、连线和游标边框使用黑色。
  • X 态边框及斜线使用灰色，二值 X 态区域使用浅灰底。
  • Z 态使用灰色中间水平线。
  • 采用明确的状态配色，没有整幅画布的灰度转换滤镜。

打印机图标只切换编辑器配色，不会直接导出 PDF 或自动打开系统打印面板。

常见问题

为什么双击波形不切换高低电平？

View 的鼠标操作只选择和定位。请先按 E，再选择 0/1 并回车。

点击 Add 后没有创建时钟？

检查面板底部的错误提示。Period 需要正数、Duty 需要介于 0 和 100 之间、Cycles 需要 1～10000 的整数，Start time 不能为负数。数字与单位分开输入。

为什么添加时钟后看到 Z？

生成器在指定周期数结束后写入 Z，表示该段时钟已结束；前面的周期仍是正常 0/1 波形。

为什么刷新后内容不同？

启动时可能恢复了本地备份。可导入之前导出的 JSON，恢复明确保存的版本。

为什么更新后仍看到旧界面？

确认访问正确入口并重新打开页面。下载版必须替换旧 HTML；在线发布后可能需要等待 GitHub Pages 更新。先导出重要工程，再尝试强制刷新。
