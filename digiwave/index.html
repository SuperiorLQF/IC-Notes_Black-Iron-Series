Properties

Verdi-Like Shortcuts

Selection & Grouping:
Ctrl + Click : 多选信号
Ctrl + G : 将选中的信号建组
Delete : 删除选中的信号/组/标尺/文本
c : 重命名 / 修改属性

Wave Editing & Measurement:
m : 开启/关闭测量标尺
s : 编辑 Bus值 / 编辑标尺注释
x / z : 设置为 Unknown/High-Z
Space : 保持并延续状态
i : 插入/移除 Time Gap (虚线间隔)

Text Annotation Layer:
:text : 进入文本编辑模式
Wheel : 滚动滑轮缩放字体
