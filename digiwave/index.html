Properties

DigiWave Shortcuts & Features

Selection & Grouping:
Ctrl + Click : 多选信号
Ctrl + G : 将选中的信号建组
Delete : 删除选中的波形(支持多选)/组/标尺/连线/文本
c : 呼出属性面板 (修改名字/颜色/单双向箭头等)

Wave Editing & Tools:
m : 开启/关闭测量标尺
a : 开启/关闭 Arrow 弧线连线模式
s : 编辑 Bus值 / 编辑标尺、连线文字
x / z : 将所选位置设置为 Unknown/High-Z
Space : 保持并延续当前波形状态
i : 插入/移除 Time Gap (虚线间隔)
Wheel : 垂直滚动轨道
Ctrl + Wheel : 缩放波形
Shift + Wheel : 水平平移波形

Text Annotation Layer:
t : 切换至 TEXT 文本层模式
:text : 命令栏进入文本编辑模式
Wheel : 在文本上滚动滑轮可缩放字体大小
