Quick guide · 操作说明

单击选择单元格，拖动或 Shift＋单击选择矩形区域；点 ✎、双击、Enter 或 F2 编辑文字。

文字编辑时选中一段文字再点格式按钮，只修改该段；未选中文字时，格式应用到选中的整个单元格。

Tab / Shift＋Tab 切换单元格，方向键移动，Shift＋方向键扩展选择。Shift＋Enter 或 Alt＋Enter 在格内换行，Ctrl＋Enter 完成编辑，Esc 取消本次文字编辑。

Ctrl＋C / X / V 复制、剪切、粘贴单元格；支持 Excel / WPS / Sheets 的 HTML 表格和制表符文本。

选中种子单元格，拖动选区右下角绿色小方块向上、下、左、右填充。单个数字按步长 1 延续；选中 1、3 后拖动可得到 5、7；支持小数、负数及 signal01 等编号。普通文本或不规则序列循环复制，按住 Ctrl / ⌘ 强制复制；Esc 取消，Undo 一次撤销。请先拆分填充路径上的合并单元格。

Merge 合并矩形内的内容，Split 将区域拆成单格，合并后的文字保留在左上格；用 Undo 可恢复合并前的内容分布。

源码输入后约 200 ms 更新预览；无效跨度或不支持的结构会保留上次有效表格，修正后继续同步。表格最多 200 行、100 列、10,000 个网格位置。

Spacing 调整整表间距：Normal（正常）、Compact（紧密）、Very compact（很紧密）。切换档位会重置固定行高，让行高随文字自适应；字号保持不变，支持撤销。Table size 设置整表宽高，右下角 ↘ 拖动缩放整表；Font 设置选中文字或单元格的字号，先点 All 可修改全表字号。拖动格子的右边界调整列宽、下边界调整行高，或用 W / H 输入像素值；尺寸作用于整列/整行，行高至少能容纳内容。颜色按钮左侧直接应用当前颜色，右侧 ▾ 展开基础色和自定义颜色；点同一色块也会立即应用。Text highlight 只给文字加底色，Cell background 给整个单元格填色。表格及草稿保存在当前浏览器，也可导出 HTML 备份。

工具无网络依赖，可下载此页离线使用。导入仅保留表格、常用文字格式和内联样式，不运行脚本或加载外部内容。
